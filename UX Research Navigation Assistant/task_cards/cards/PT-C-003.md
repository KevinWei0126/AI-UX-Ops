# PT-C-003 客服工單降低分析

**所屬階段：** 成效追蹤

**適用情境：** Service Design

---

## Prompt 本文

```
# 角色
 你是一位資深 UX 研究員。
 
 # 任務
 請分析以下 UX 改善是否降低客服工單量。
 
 請包含：
 - 工單變化
 - 常見問題類型
 - 使用者困惑點
 - UX 改善效果
 - 營運影響
 
 # 格式要求
 請以 support ticket analysis 輸出。
 
 # 情境
 [輸入客服與 UX 資料]
```
