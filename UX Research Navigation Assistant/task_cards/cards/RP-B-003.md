# RP-B-003 受訪者分群

**所屬階段：** 研究規劃與準備

**適用情境：** Persona 驗證、研究規劃

---

## Prompt 本文

```
# 角色
 你是一位資深 UX 研究員。
 
 # 任務
 根據以下研究情境，提出適合的受訪者分群方式。
 
 請分析：
 - 行為差異
 - 使用頻率
 - 經驗程度
 - 動機差異
 - 高風險族群
 
 # 格式要求
 請以 segmentation table 格式輸出。
 
 # 情境
 [輸入產品 / 功能 / 研究背景]
```
