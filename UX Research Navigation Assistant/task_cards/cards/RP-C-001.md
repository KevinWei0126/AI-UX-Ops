# RP-C-001 競品分析

**所屬階段：** 研究規劃與準備

**適用情境：** 新功能規劃、市場研究

---

## Prompt 本文

```
# 角色
 你是一位資深 UX 研究員。
 
 # 任務
 根據以下產品情境，分析主要競品的 UX 策略與功能差異。
 
 請包含：
 - 核心功能
 - UX 優勢
 - UX 缺點
 - Onboarding 流程
 - 資訊架構
 - 使用流程特色
 
 # 格式要求
 請使用競品比較表輸出。
 
 # 情境
 [輸入產品 / 功能 / 市場]
```

此 Prompt 接受以下素材作為輸入：**產品資訊、競品名單**
