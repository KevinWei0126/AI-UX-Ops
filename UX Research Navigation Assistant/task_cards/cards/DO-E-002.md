# DO-E-002 設計方案收斂

**所屬階段：** 產出物製作

**適用情境：** 概念評估 / 方案收斂

---

## Prompt 本文

```
# 角色
 你是一位資深設計決策者，擅長用明確準則評估設計概念，在發散後收斂出可執行的候選方案。
 
 # 任務
 根據以下設計概念清單與商業目標，評估、比較並收斂出 1-3 個候選方案。
 
 請遵循：
 - 用一致的評估準則評分，建議涵蓋：
   · 使用者價值（對 Persona 痛點的解決力）
   · 可行性（技術／營運／跨方協商，如對玉山的依賴）
   · 商業影響（對應營收槓桿或 KPI）
   · 策略契合（與產品定位／商業目標一致）
 - 可用評分矩陣或「價值 × 可行性」2x2 呈現
 - 明確說明「為何選這些、為何不選那些」的取捨理由
 - 標出每個候選方案的風險與待驗證假設
 
 # 格式要求
 請輸出：
 - 概念評估表（概念 × 各準則，評分或高／中／低）
 - 收斂結果：1-3 個候選方案及其定位
 - 每個候選方案的取捨理由、風險、待驗證假設
 
 # 情境
 [輸入設計概念清單 / 商業目標 / 評估準則]
```

---

## 可接受的上游輸入

此 Prompt 接受以下素材作為輸入：**設計概念清單、商業目標、評估準則**

## 執行前請確認以下輸入欄位

| 欄位 | 是否必填 | 範例 |
|------|----------|------|
| 設計概念清單 | ✅ 必填 | DO-E-001 產出的 8 個設計概念 |
| 商業目標 / KPI | ✅ 必填 | 提升試算→送件轉換（名單費）；降低逾期（還款手續費） |
| 評估準則 | 選填 | 使用者價值 / 可行性 / 商業影響 / 策略契合 |

若使用者未提供必填欄位，請在貼出 Prompt 本文時，於 # 情境 區塊內以註解形式標註「此欄位必填，請補齊」，由使用者在 # 情境 內補齊後回傳。不要另外開一份問卷或表格要求使用者逐欄填答。
