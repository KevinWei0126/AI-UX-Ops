**適用情境：** 功能策略分析

## Prompt 本文

```
# 角色
 你是一位資深 UX 研究員。
 
 # 任務
 請比較以下競品功能差異。
 
 請分析：
 - 功能完整度
 - 操作流程
 - 使用門檻
 - 差異化特色
 - 缺漏功能
 
 # 格式要求
 請以 feature comparison table 輸出。
 
 # 情境
 [輸入產品 / 功能 / 競品]
```
