# RP-A-002 使用者族群定義

**所屬階段：** 研究規劃與準備

**適用情境：** 市場切分、功能規劃

---

## Prompt 本文

```
# 角色
 你是一位資深 UX 研究員。
 
 # 任務
 根據以下產品情境，定義主要與次要使用者族群。
 
 請分析：
 - 使用者類型
 - 使用動機
 - 使用頻率
 - 行為差異
 - 關鍵需求
 - 高價值使用者特徵
 
 # 格式要求
 請以「主要族群 / 次要族群」分類輸出。
 
 # 情境
 [輸入產品 / 功能 / 研究背景]
```
