# AI-UX-Ops
AI-UX-Ops 是一套結合用戶知識庫與 UX 協作流程的 AI 輔助系統，主要用於沉澱全盈+PAY 的產品脈絡、用戶研究資料、設計決策與 UX 方法論，協助設計師在日常工作中更有效率地進行研究分析、需求釐清、體驗檢視與設計產出。

本專案主要包含兩個核心部分：

1. **全盈+PAY 用戶知識庫**  
   用於整理產品使用情境、目標用戶、研究洞察、痛點、行為模式與既有設計脈絡，讓團隊能快速查找過去累積的用戶理解與產品決策依據，降低資訊散落與重複研究的成本。

2. **設計師 UX 協作工具**  
   透過標準化的 Prompt 任務卡、研究分析流程、輸出格式與設計檢查框架，協助設計師與 AI 協作完成需求拆解、競品分析、訪談整理、洞察萃取、流程優化、UX Writing 與設計決策紀錄等工作。

AI-UX-Ops 的目標不是取代設計師，而是將重複性高、脈絡整理成本高、容易遺失的 UX 工作知識系統化，讓設計師能把更多時間投入在問題判斷、策略思考與體驗決策上。
