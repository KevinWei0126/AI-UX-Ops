# business-goals/

> 全盈+PAY 的商業目標（KPI、OKR、季度目標、改版要解決的商業問題）。

## 這裡放什麼？

- **季度／年度目標**：每季要達成的具體商業數字
- **改版商業背景**：每個大改版背後想解決的商業問題
- **目標達成回顧**：goal 結束後的覆盤

> 此資料夾是「**設計工作的最上層依據**」——所有 persona、insight、design 最終都要能對應到某個商業目標。

## 命名規則

- `bg-{年}-{Q季}-{主題}.md`
- 例如：
  - `bg-2025-Q2-提升首購轉換率.md`
  - `bg-2025-Q3-增加交易頻次.md`
  - `bg-2025-annual-擴大商家覆蓋.md`

## 新增流程

1. 複製 `../_meta/templates/business-goal.template.md`
2. 必填：成功指標、目前數值、目標值、量測方式
3. 列清楚「假設」——這是後續驗證設計是否有效的依據
4. 在 `CHANGELOG.md` 加 Added 一筆
5. 執行 `bash ../scripts/generate_file_map.sh`

## 維護原則

- **每月進度更新**請寫在該檔的「進度更新」段，不要每月開新檔
- 目標達成或結束時，請填「達成回顧」段並將 `status` 改為 `validated`（已驗證）或 `deprecated`（已過期，學習保留）
- 失敗的目標**特別重要**——保留並寫清楚為什麼沒達成，是團隊最珍貴的學習
- 此資料夾要與 OKR／PRD 系統對齊（在內文標 OKR 連結）
