# product-context/

> 全盈+PAY 的產品脈絡（產品定位、核心流程、商業模式、競品、法規限制）。

## 這裡放什麼？

- **產品定位**：我們是誰？跟誰競爭？差異化在哪？
- **核心流程**：支付、註冊、KYC、綁卡、退款等業務流程的**現況描述**（不是設計建議）
- **商業模式**：手續費結構、合作對象、營收來源
- **法規限制**：金管會、洗錢防制、個資法等對設計的影響
- **競品分析**：跟 LINE Pay、街口、Apple Pay 等的比較

> 這個資料夾的內容相對穩定（產品脈絡不會天天變），但**法規與商業模式變動時必須立刻更新**。

## 命名規則

- `pc-{主題}.md`
- 例如：
  - `pc-產品定位.md`
  - `pc-核心流程-支付.md`
  - `pc-核心流程-KYC.md`
  - `pc-法規-洗錢防制.md`
  - `pc-競品-LINE-Pay.md`

## 新增流程

1. 複製 `../_meta/templates/product-doc.template.md`
2. 寫清楚「TL;DR」段——新人看一段就理解
3. 在 `CHANGELOG.md` 加 Added 一筆
4. 執行 `bash ../scripts/generate_file_map.sh`

## 維護原則

- **TL;DR 必填**——這資料夾是新人 onboarding 的主要入口
- 若引用外部資料（法規條文、市場報告），請附連結與查閱日期
- 法規類檔案請在 frontmatter 標 `category: 法規限制`，並設定 6 個月 review 一次
